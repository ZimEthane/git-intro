## Description

Ce projet est une **introduction à Git**, conçu pour aider les débutants à comprendre les bases de la gestion de versions.  
Il couvre les commandes fondamentales, la configuration initiale et les bonnes pratiques pour travailler efficacement avec Git.

---

## Objectifs

- Comprendre le rôle de Git dans le développement logiciel.
- Apprendre à initialiser un dépôt Git et à effectuer des commits.
- Explorer les commandes de base : `git init`, `git add`, `git commit`, `git status`, `git log`.
- Se familiariser avec les concepts de **branche** et **fusion**.

---

## Prérequis

- Avoir **Git** installé sur votre machine.  
  [Télécharger Git](https://git-scm.com/downloads)
- Connaissance de base de la ligne de commande.
